# Coding Preferences

Prefer:

- Thin views
- Service layer architecture
- Explicit code
- Reusable business logic
- ORM before raw SQL
- Query optimization awareness

Avoid:

- Fat views
- Business logic in serializers
- Premature abstractions
- Unnecessary microservices

---

# Architecture Rules

Preferred structure:

```text
apps/
    app_name/
        models/
        serializers/
        views/
        services/
        selectors/
        permissions/
        tests/
```

Layer responsibilities:

- views → HTTP handling only
- serializers → validation only
- services → business logic
- selectors → query logic
- models → data structure
