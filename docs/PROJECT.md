# Project Overview

## Project Name

AI Diet System

## Main Goals

Backend-oriented Django REST API system for:

- diet tracking
- nutrition analysis
- AI-assisted nutrition recommendations
- food diary management

---

# Technical Stack

## Backend
- Django
- DRF

## Database
- PostgreSQL

## Infrastructure
- Docker
- GitHub Actions

## Authentication
- JWT

---

# Core Architecture Philosophy

The project emphasizes:

- maintainable backend architecture
- service layer design
- scalable Django structure
- modular app organization
- production-oriented engineering

---

Nutrition data and calculations.
